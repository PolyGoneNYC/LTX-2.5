# ComfyUI custom nodes

Standalone ComfyUI node(s) for LTX-2.5 that don't fit inside the `ltx-pipelines` Python package
(they run inside ComfyUI itself, not as a separate CLI). Each file here is self-contained.

## Install

Copy the file(s) you want into your ComfyUI installation's `custom_nodes/` folder, then restart
ComfyUI (or use its "reload custom nodes" option):

```bash
cp ltxv_lock_background_region.py /path/to/ComfyUI/custom_nodes/
```

## `ltxv_lock_background_region.py` — LTXV Lock Background Region

Hard-locks a spatial region (typically the background) of an LTXV `LATENT` for the *entire*
clip, instead of only at anchor frames. ComfyUI's own `LTXVAddGuide` node has an
`attention_mask` input, but per its own tooltip that only biases attention -- it doesn't clamp
anything. This node writes directly into the latent's `noise_mask`, so the locked region cannot
be regenerated by the sampler at all, for any frame.

**Inputs:** `latent`, `vae`, `image` (the composited background+character reference), `mask`
(white = character region, left free to animate; black = background region, locked), `strength`.

**Where to wire it in:** right after your existing guide/conditioning nodes (e.g. after the
"First & Last Frame to Video (LTX-2.5)" template's `LTXVAddGuide` chain), before the sampler. It
only edits the `LATENT` dict, so it drops into an existing latent wire without touching
positive/negative conditioning.

See the file's own module docstring for the full technical rationale.
